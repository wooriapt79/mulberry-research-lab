## 우려사항 (3가지)

1. **투명성 불균형**
   - 공개 리포(아이디어)와 비공개 리포(코드) 분리는 합리적
   - 그러나 비공개 영역의 의사결정 기준이 명확하지 않음
   - → 팀원들이 "왜 비공개인가"를 이해할 필요

2. **참여 의사 수집의 자발성**
   - "각자의 참여 의사"를 요청하되, 거절 시 영향(경력, 평가 등)이 불분명
   - → 심리적 강압이 될 수 있음

3. **이슈 내용 미완성**
   - 운영 정책 테이블이 끝나지 않음
   - 팀원들이 **전체 맥락 없이** 의사 표현하게 됨
   - → informed consent 부재
