## 🧠 멀티모달 아키텍처

```
[물리 세계]
    │
    ├── 마이크 → STT (Whisper / Clova)
    │              ↓
    ├── 카메라 → 시각 인식 (표정·낙상·상황)
    │              ↓
    ├── LiDAR  → 공간 인식 (이동패턴·거리·장애물)
    │              ↓
    └──────────────────────────────
                   ↓
         TRANG Tokenizer
         (도메인 분류: 돌봄·알림·대화·긴급)
                   ↓
         Luna API 호출
         (Context Mode + Resonance AI)
                   ↓
         응답 생성 + 판단
                   ↓
    ┌──────────────────────────────
    │
    ├── TTS → 스피커 출력 (음성 응답)
    ├── 모터 → 물리적 이동 (다가가기)
    └── 알림 → 보호자 앱 전송 (긴급 시)
```

## 🗺️ 바디 유형별 존재 방식

| 바디 | 공간 | TRANG Manager의 역할 |
|------|------|---------------------|
| 로봇청소기 (Oomwoo) | 집 전체 · 야외 | 이동하며 함께 있는 존재 |
| 냉장고 | 거실·주방 | "밥은 먹었니?" 말을 건다 |
| 스피커 | 침실·사무실 | 잠들기 전 목소리 |
| 스마트폰 | 어디서나 | 이동 중에도 함께 |

**핵심:** 로봇에 AI를 넣은 것이 아니라 — TRANG Manager가 바디를 선택해서 들어가는 구조.

## 🛣️ 단계별 구현 로드맵

### Step 1 — 음성 연결 (즉시 시작 가능)
```
목표: Raspberry Pi 5에서 Luna API 호출
구현:
  ├── STT: Whisper (로컬) or Clova (API)
  ├── Luna API 연결 (POST /api/agents/jr-trang)
  └── TTS: pyttsx3 or Google TTS
결과: 말하고 대답하는 TRANG Manager
난이도: ⭐⭐
```

### Step 2 — 시각 연결
```
목표: 카메라로 상황 인식
구현:
  ├── Pi Camera 또는 USB 웹캠
  ├── OpenCV 기본 인식 (움직임·낙상)
  └── 인식 결과 → Luna API 컨텍스트에 추가
결과: 보고 인식하는 TRANG Manager
난이도: ⭐⭐⭐
```

### Step 3 — 공간 인식
```
목표: LiDAR로 집 안 매핑
구현:
  ├── ROS 2 SLAM (집 구조 파악)
  ├── 이동 패턴 기록 (평소 vs 오늘)
  └── 이상 감지 → 알림 발송
결과: 공간을 아는 TRANG Manager
난이도: ⭐⭐⭐⭐
```

### Step 4 — 통합 멀티모달
```
목표: 모든 센서 + Luna 완전 통합
구현:
  ├── 음성 + 시각 + 공간 동시 처리
  ├── 상황별 자율 판단 (돌봄·긴급·대화)
  └── LMA 연동 (기억 기록 + 가족 알림)
결과: 완전한 물리적 TRANG Manager
난이도: ⭐⭐⭐⭐⭐
```
